First-run activation — default to hosted models

The single highest-leverage activation change. Replace the empty dashboard + invisible LLM-key cliff with a 3-step checklist where hosted models are pre-selected, so a brand-new user can generate their first hiring plan with zero setup.

Why it does NOT add complexity: it removes a hard dead-end (the /hire "no LLM config" block). One additive card on an otherwise-empty screen; it disappears the moment the workspace has a mission. No new nav, no new vocabulary.
