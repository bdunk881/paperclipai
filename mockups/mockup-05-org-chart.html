Agent org chart — the differentiator, made visual

"A workforce, not a flowchart" is the wedge n8n/Zapier structurally can't copy — but OrgStructure is a collapsible card-list, and the product's own E2E test asserts a graph (data-testid="org-chart-node") that doesn't exist. Render the real manager→report graph from org_edges with live presence.

Why it stays simple: one node card per agent (same density as today's cards), generous spacing, calm palette — presence reuses the exact sage/mustard/clay status dots. Detail stays behind a click (node → AgentDetail); the canvas itself shows only name, role, current task, and month-to-date spend. ReactFlow is already a dependency (Studio uses it).
